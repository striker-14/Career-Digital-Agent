AI Agent: 1. AI systems where an LLM controls the workflow. AI systems that can work for you independently.
          2. An LLM with Tools in a loop to achieve a goal.

Workflows: are systems where LLM and tools are orchestrated (carefully planned, organized) through predefined code paths.

Before an AI can process your prompt, an algorithm breaks the raw text down into individual token fragments.
In English, one token equals about 4 characters

Risks of Agent Frameworks:
1. Unpredictable path
2. Unpredictable output (you might get different outputs each time you run it)
3. Unpredictable costs (cost of running our agentic system might vary, it might be different every time)

Mitigate (Avoid, Reduce) Risks:
1. Monitoring
2. Guardrails (ensure our agents behave safely, consistently, and within our intended boundaries) (is code that you put on, it's sort of scaffolding our code that we build around our agent workflow, that ensures it follows various rules) (typically it's just tests that we add)

Anthropomorphizing (treat AI Agents as if they're human-like in some way)

Key Takeaways:
1. Build Agents systems to solve problems in a measurable way.
2. Decide your Agent architecture based on performance.
3. LLMs generate plausible (that we can believe) outputs, not necessarily accurate outputs.
   Aligning the outputs with business results? That's our job.

Agent Loop: an LLM in a loop with tools to achieve a goal

* The reality is that we've written some software that in a loop repeatedly calls an LLM and based on the response we may decide to also call some functions and then keep calling the LLM.
It's our software that's calling the tools. LLM just takes input tokens and gives output tokens.
